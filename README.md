# BiliBeat

A Flutter music player for Bilibili audio with synced LRC lyrics and offline caching.

## Downloads

- [GitHub Releases Page](https://github.com/Aeacu2/BiliBeat/releases)

## Build

```bash
flutter build apk --split-per-abi --release
```

Output APKs will be located at `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`.
